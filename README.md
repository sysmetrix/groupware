# GW 비서

[![CI](https://github.com/sysmetrix/groupware/actions/workflows/ci.yml/badge.svg)](https://github.com/sysmetrix/groupware/actions/workflows/ci.yml)
[![최신 릴리스](https://img.shields.io/github/v/release/sysmetrix/groupware?label=%EB%A6%B4%EB%A6%AC%EC%8A%A4)](https://github.com/sysmetrix/groupware/releases/latest)

로그인된 더존 Amaranth 10 그룹웨어(부천여성청소년재단 `gw.bwyf.or.kr`) 위에 띄워 쓰는 **한 화면 업무 비서**입니다. 결재·메일·근태·예산·일정·자원 예약·할 일·문서 찾기를 한곳에서 보고, 그룹웨어 원래 화면을 오른쪽 처리 창에 열어 그 자리에서 처리합니다. 별도 서버 없이 브라우저 안에서만 동작합니다.

## 지키는 약속

- **마지막은 사람이 누릅니다.** 상신·결재·임시저장·삭제·발송은 코드로 막혀 있고, 기안·신청서 자동 입력은 상신·신청 직전에서 멈춥니다. 자원 예약만 사용자가 확정하면 등록합니다.
- **하지 않은 일을 했다고 말하지 않습니다.** 조회하지 못한 범위와 실패를 그대로 표시합니다.
- **자료는 이 브라우저에 남습니다.** AI(Gemini)를 연결하면 질문에 답하는 데 쓰는 정보가 Google로 전송되며, 그 범위는 연결 전에 안내합니다.
- **그룹웨어에서 온 글자는 믿지 않습니다.** 제목·본문·이름은 이스케이프하고, AI에는 지시가 아닌 자료로만 넘깁니다.

## 설치

PC마다 한 번 설치하면 그룹웨어를 열 때마다 “GW 비서” 버튼이 뜨고, 새 버전은 저절로 바뀝니다(쓰는 중에는 바꾸지 않습니다). Chrome 111 이상 또는 Edge가 필요합니다.

1. [시작 페이지](https://sysmetrix.github.io/groupware/)에서 확장 프로그램(zip)을 내려받아 지워지지 않을 곳(예: `문서\gw-bisu-extension`)에 압축을 풉니다.
2. `chrome://extensions`(Edge는 `edge://extensions`)에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 푼 폴더를 고릅니다.
4. 그룹웨어에 로그인한 뒤 새로고침하면 버튼이 나타납니다. 단축키는 <kbd>Alt</kbd>+<kbd>G</kbd>입니다.

설치할 수 없는 PC에서는 시작 페이지의 북마크 “GW 비서 열기”를 씁니다. 그룹웨어를 새로 열 때마다 북마크를 눌러야 합니다.

저장소를 직접 받아 만들었다면 `npm run live:build` 뒤 `build/live/extension` 폴더를 3번에서 고르면 됩니다.

문제가 생기면:

- **“gw-live.js가 UTF-8로 인코딩되지 않았습니다”**: v1.30.0 이하 빌드의 오류입니다. v1.30.1부터 고쳐졌으니 최신 zip(또는 다시 빌드한 폴더)으로 로드하세요.
- **새로고침하면 버튼이 사라짐**: 확장 프로그램이 설치돼 있지 않거나 꺼져 있는 경우입니다. `chrome://extensions`에서 “GW 비서”가 켜져 있는지 보세요.
- **예전에 설치한 확장이 스스로 최신화하지 못함**: 한 번만 삭제하고 새로 로드하면 이후부터 저절로 바뀝니다. 설정과 할 일은 남습니다.

## 할 수 있는 일

| 영역 | 내용 |
|---|---|
| 홈 | 지금 할 일 하나, 오늘 일정 흐름, 결재·메일·근태·예산 요약, 비서에게 묻는 대화창 |
| 결재·메일 | 기다리는 결재, 접수·배부 추천, 연속 처리, 메일 읽기와 답장 초안, 통합검색(열람 기록 없음) |
| 할 일 | 그룹웨어 ToDo와 연동, 첨부, 반복, 마감 알림, 끌어서 옮기는 보드 |
| 일정·예약 | 일정 달력, 자원·차량 예약(확정은 사용자), 구글 캘린더 일 보기와의 읽기 대조 |
| 근태·연차 | 근태 교차 확인, 휴가 마감 경고, 근태 신청서 미리 채우기 |
| 예산 | 사업별 집행 현황, 연말 집행률 전망, 월별 그래프, 결의 대조 |
| 기안 | 결과보고·지출 기안 미리 채우기(상신 직전에서 멈춤), 주간 실적 초안, 한글용 복사 |
| 기타 | Ctrl+K 명령 팔레트, 밝게·어둡게 화면, 설정 내보내기·가져오기 |

화면별 설명은 [업무센터 안내](docs/live-collector.md)에 있습니다. 로그인 없이 화면만 먼저 보려면 아래 `npm run live:demo`를 실행하세요(지어낸 자료, 그룹웨어에 요청하지 않음).

실제 그룹웨어에서 끝까지 확인하지 못한 동작(실제 상신·접수·배부·발송·예약 확정)이 있습니다. 업데이트 내역은 [릴리스](https://github.com/sysmetrix/groupware/releases)와 앱 안 왼쪽 아래 버전 표시에서 볼 수 있습니다.

## 개발

Node.js 24 이상이 필요합니다. 런타임 의존성은 없습니다.

```bash
npm ci
git config core.hooksPath .githooks   # 새 PC에서 한 번: 푸시 전에 전체 하네스를 돌립니다
npm run live:demo                     # http://127.0.0.1:3220 에서 둘러보기
```

| 명령 | 하는 일 |
|---|---|
| `npm run harness:fast` | 구문, 코드 그래프, 핵심 테스트 (약 2초) |
| `npm run harness` | 전체 테스트, 빌드, 번들 크기, 안전 규칙, 비밀 점검 |
| `npm run e2e` | 둘러보기를 Chrome·Edge에 띄워 핵심 여정을 사람처럼 눌러 봅니다 |
| `npm run eval:chat` | 대화 평가 문항으로 비서의 로컬 규칙을 채점합니다 |
| `npm run live:build` | 번들과 확장 프로그램을 `build/live`에 만듭니다 |
| `npm run bump -- <새 버전> "제목" "바뀐 점"` | 버전과 업데이트 내역을 한 번에 올립니다 |

### 배포

1. `npm run bump -- 1.2.3 "제목" "바뀐 점"`으로 버전을 올립니다.
2. `npm run harness`를 통과시키고 PR을 엽니다. main은 PR과 Ubuntu·Windows CI 통과가 필요합니다.
3. main에 합치면 GitHub Pages 시작 페이지와 GitHub 릴리스가 자동으로 만들어집니다. 사용자의 확장 프로그램은 새 번들을 스스로 받아 갑니다.
4. 배포 뒤 공개된 `current.json`의 SHA-256이 로컬 `build/live/gw-live.sha256`과 같은지 확인합니다.

Windows CI는 서비스 시작 테스트가 가끔 시간 초과로 실패합니다. 코드와 무관한 경우가 많아 재실행으로 확인합니다.

### 저장소 구조

| 경로 | 내용 |
|---|---|
| `src/live/wc/` | 화면 조각. 파일명 순으로 이어 붙어 하나의 번들이 됩니다 |
| `src/live/*.mjs` | 계산·판정 순수 함수(브리핑, 대화, 홈, 예산 등)와 업데이트 내역 |
| `src/live/ext/` | 확장 프로그램의 서비스 워커와 다리 스크립트 |
| `scripts/` | 빌드, 하네스, E2E, 둘러보기 서버, 시작 페이지 생성 |
| `test/` `eval/` | 단위 테스트와 대화 평가 문항 |
| `docs/` | 설계 원칙, 개발 하네스, 보관 문서 |
| `src/*.mjs` `public/` `desktop/` | 2026년 10월 로컬 서버 도우미(보관) |

고치는 순서와 규칙은 [개발 하네스](docs/engineering/HARNESS.md), 평가와 방향은 [평가와 지향점](docs/engineering/direction.md), 화면 기준은 [디자인 원칙](docs/design/principles.md), AI 비서 기준은 [성공 기준](docs/ai-success-criteria.md), 에이전트 작업 규칙은 [CLAUDE.md](CLAUDE.md)에 있습니다.

실제 그룹웨어 화면의 동작은 둘러보기로 확인되지 않습니다. 출시 전에는 그룹웨어 탭에서 `scripts/live-smoke.browser.js`(읽기 전용)를 돌려 확인합니다.

## 보관: 로컬 서버 도우미

2026년 10월에 만든 로컬 우선 업무 브리핑·규정 검색·초안 점검 도구(`src/*.mjs`, `public/`, `desktop/`)입니다. GW 비서와 따로 도는 별도 프로그램이며, 실제 그룹웨어에 로그인하거나 자료를 수집하지 않습니다. 실행 방법과 기능은 [로컬 서버 도우미 안내](docs/local-helper.md)에 있습니다. 테스트와 CI는 계속 돌립니다.
