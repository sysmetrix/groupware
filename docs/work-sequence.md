# 남은 작업 순서와 의존성

## 2026-10-23 후속 실행 결과

1. **현재 PC 설치·실행 도구 보완 완료**: 설치와 업데이트가 데스크톱 실행 파일·바로가기를 함께 갱신한다. 실행 중이거나 잠긴 관리자는 덮어쓰지 않고 Git/npm 작업 전에 조치 방법을 안내한다.
2. **깨끗한 복제본 검증 완료**: GitHub에서 한글·공백 경로로 새로 복제해 초기 설정, 별도 문서 Python 환경, Node 89개·Python 9개 테스트와 실행 파일 빌드를 확인했다. 실제 다른 물리 PC 검증은 남아 있다.
3. **반복 가능한 설치 진단 완료**: `npm run verify:pc`가 HTML/JSON 결과를 생성한다. 기존 업무자료를 사용하지 않는 합성 HTTP 흐름, 설치 조건, 모델 설치 상태를 검사한다. 미설정 AI는 SKIP, 누락 모델은 FAIL로 확인했다.
4. **현재 PC 합성 LLM 재검증 완료**: 브리핑 추론과 금액 근거·문서 내 잘못된 지시·근거 없음 평가 3종 통과. 기관 규정 정확도를 의미하지 않는다.
5. **실제 연결부터 대기**: 브라우저 버전은 오류가 재현된 0.6.0.16 그대로이며 공식 조회 계약이 아직 없다. 아래의 실제 연동 순서를 계속 적용한다. 자료 의존성을 코드 검증으로 대체하거나 전체 완료·머지로 표시하지 않는다.

## 병렬 진행

| 작업 | 완료 증거 | 외부 의존성 |
|---|---|---|
| 문서 저장·삭제 복구 | 삭제 실패 복원, 고아 파일 정리, 원본 크기 제한, 손상된 색인 거부 회귀 테스트 | 없음 |
| 실행 상태·종료 관리 | 앱 화면의 서버/모델/메모리 구분, 프로젝트 소유 프로세스 관리 명령 | Windows 실행 검증 |
| 브라우저 연결 복구 | 버전·경로 확인, 공식 업데이트, 사용자 재시작 후 재현 기록 | 브라우저 공간 생성 직후 실패가 해결되어야 함 |

## 실제 연동은 순차 진행

1. **브라우저 공간 유지 확인** 또는 공급사가 제공한 공식 조회 계약 확보. 현재 이 단계가 막혀 있다.
2. **현재 계정의 결재·일정 정상 조회 관찰**. 사용자·조직, 조회 조건, 원문 ID, 상태, 전체 건수·페이지, 세션 만료를 기록한다.
3. **읽기 커넥터 구현**. 확인된 요청·응답만 정규화 페이지 처리와 연결한다. 실패한 부분 수집은 게시하지 않는다.
4. **원문과 실제 건수·상태·기한 대조**. 삭제·권한 회수·조직 변경·429를 검증한다. 성공 후 실제 연결 상태를 표시한다.
5. **기관 첨부·규정 적용**. 열람 가능한 실제 표본에서 추출 위치·숫자 의미와 시행 중인 규정·필수 서식을 확인하고 기대 결과로 평가한다.
6. **변경 작업**. 테스트 가능한 초안 저장 대상과 계약을 확인하고, 변경 미리보기·사용자 승인·버전 확인·중복 방지·결과 재조회를 구현한다.
7. **통합·다른 PC 검증 → HTML 보고서 확정 → 머지**. 실제 로그인을 요구하는 검증은 사용자가 수행할 수 있는 시점에 진행한다.

독립적인 코드 수정을 완료해도 1~6의 실증 자료가 없으면 전체 완료로 표시하지 않는다. 합성 테스트·로컬 파일 검색·모델 추론 성공은 실제 그룹웨어 자동 수집의 완료 증거가 아니다.
