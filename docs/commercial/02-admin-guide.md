# 관리자 배포 가이드

## 배포 방법 (크롬/엣지, 관리자 PC)
1. 릴리스의 `gw-live-extension-vX.zip`을 받아 공유 폴더에 풀고, 해시(`gw-live.sha256`)가 릴리스와 같은지 확인합니다.
2. 폴더의 `policy.js`를 기관 설정에 맞게 수정합니다(아래 표).
3. 각 PC: 확장 프로그램 관리 → 개발자 모드 → 압축해제된 확장 로드. 기관 정책이 허용하면 그룹 정책(ExtensionInstallForcelist)으로 배포합니다.
4. 그룹웨어(https://gw.bwyf.or.kr)에 로그인하면 상단에 “업무센터” 버튼이 나타납니다. 최초 실행 시 사용 안내가 표시됩니다.

## policy.js 설정
| 항목 | 의미 |
|---|---|
| enabled | false로 배포하면 전체 중지(긴급 차단). 사용자에게 message가 표시됩니다 |
| features.* | briefing, draftResult, draftPlan, draftPay, draftGoods, recorder, aiConsole, updateCheck 각각 차단 |
| retentionDays | 학습한 결재문서 보관일(7~365, 기본 90) |
| orgName, message | 안내 화면 문구 |
기록기 재생 시 비가역 버튼 확인은 정책으로 끌 수 없습니다.

## 점검과 지원
- 사용자 PC: 업무센터 → 설정 → 진단 → “진단 보고서 복사”(이메일·전화·사번 자동 마스킹)를 지원 담당자에게 전달.
- 그룹웨어 화면이 개편되면 자동 입력 단계가 ✗로 표시됩니다. 이때 해당 기능만 policy.js로 차단하고 수정판을 받습니다.
- 업데이트: 진단 화면이 GitHub 최신 릴리스를 조회해 새 버전을 알립니다. 자동 설치는 하지 않으며 관리자가 위 1~3을 반복합니다.

## 변경 관리 권장
시범 그룹 먼저 배포, 1주 관찰 후 전체 배포. 이전 버전 폴더는 보관해 두고 문제 시 되돌립니다.
