# 소프트웨어 사용 허락 계약 (초안, 변호사 검토 전)

1. 허락: 계약 기관은 구독 기간 동안 약정한 사용자 수만큼 소프트웨어를 설치해 업무에 사용할 수 있다.
2. 금지: 재판매, 역설계, 약정 외 기관에서의 사용. 그룹웨어 제공사의 약관을 위반하는 사용.
3. 보조 도구: 소프트웨어는 입력 보조 도구이며 상신·결재 판단과 문서 내용의 정확성은 사용자가 책임진다.
4. 데이터: 기관의 업무 데이터는 사용자 브라우저에만 저장되며 공급자는 접근하지 않는다. 지원 시 사용자가 제공한 진단 보고서만 처리한다.
5. 제3자 시스템: 그룹웨어 화면이 변경되어 동작하지 않을 수 있으며, 공급자는 합리적 기간 안에 수정판을 제공하도록 노력한다. 변경으로 인한 일시 중단은 장애로 보지 않는다.
6. 책임 제한: 공급자의 책임은 직전 12개월간 지급받은 이용료를 한도로 한다(법이 허용하는 범위).
7. 지원: 응답 시간, 유지보수 범위, 요금은 별도 합의로 정한다. [미정]
