# 보안·개인정보 설명서 (초안, 법률 검토 전)

## 데이터 흐름
- 업무센터는 사용자 브라우저 안에서만 동작합니다. 재단 그룹웨어(gw.bwyf.or.kr) 외 서버로 업무 데이터를 보내지 않습니다.
- 유일한 외부 통신: 새 버전 확인을 위한 GitHub API 조회(버전 번호만 받음, 업무 데이터 전송 없음). policy.js에서 끌 수 있습니다.
- 저장 위치: 브라우저 localStorage, 사용자(사번)별 분리. 학습한 결재문서(제목, 본문, 기록물철 등), 기록기 기록, 감사 기록, 설정.
- 비밀번호·인증정보는 읽지도 저장하지도 않습니다. 기록기는 비밀번호 입력란을 기록에서 제외합니다.

## 통제
| 통제 | 내용 |
|---|---|
| 쓰기 차단 | 자동 입력 중 상신·결재·임시저장·보내기·삭제·승인·반려 버튼 클릭을 코드로 차단 |
| 사전점검 | 열린 팝업, 편집기 준비, 기존 입력 덮어쓰기 확인 |
| 실패 중단 | 단계 실패 시 해당 팝업만 닫고 이후 단계 중단 |
| 보존 | 학습 문서 90일(조정 가능) 후 자동 삭제, 사용자가 데이터 관리 화면에서 즉시 삭제 |
| 감사 | 자동 작업마다 기록, SHA-256 해시 체인으로 수정·삭제 감지, JSON 내보내기 |
| 정책 | 관리자가 기능별·전체 차단 |

## 알려진 한계 (고객에게 고지해야 함)
- localStorage는 암호화되지 않아, PC에 접근 가능한 사람은 학습 자료를 볼 수 있습니다. 공용 PC 금지 또는 사용 후 삭제 필요.
- 감사 기록은 사용자 브라우저에 있어 관리자가 중앙에서 수집하지 못합니다. 해시 체인은 변조를 "감지"할 뿐 막지는 못하며, 전체 삭제는 막을 수 없습니다.
- 외부 보안성 검토, 모의 침투 시험은 받지 않았습니다.
- 개인정보 처리 근거, 위탁 해당 여부, 개인정보 영향평가 필요성은 법률 검토 전입니다.
