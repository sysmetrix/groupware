# 사용자 매뉴얼

## 시작
그룹웨어에 로그인하면 상단 “업무센터” 버튼(또는 Alt+G). 처음 열면 사용 안내가 나옵니다.

## 자주 쓰는 일
| 하고 싶은 일 | 방법 |
|---|---|
| 오늘 처리할 일 보기 | 업무센터 첫 화면 |
| 결과보고 기안 | 새로 만들기 → 결과보고 → 계획서 선택. 제목, 기록물철, 결재라인, 참조문서, 본문이 채워지고 상신 직전에서 멈춥니다 |
| 지급 건의 | 새로 만들기 → 지급 문서 → 지난 건의 선택 → 금액·근거 계획서 확인 |
| 지출결의서 | 같은 화면 ③에서 제목, 참조문서, 금액(한글)을 복사해 양식에 붙여넣기 |
| 반복 작업 자동화 | 새로 만들기 → 기록기 → 기록 시작 → 평소처럼 작업 → 정지·저장. 재생 시 값 입력창이 나옵니다 |

## 꼭 지켜 주세요
- 채워진 결과 보고서의 ✗ 항목, 금액, 결재라인, 기록물철은 직접 확인하세요.
- 상신은 반드시 본인이 합니다. 도구는 상신하지 않습니다.
- 공용 PC에서는 설정 → 데이터 관리에서 자료를 지우세요.

## 문제가 생기면
설정 → 진단 → “진단 보고서 복사” 후 담당자에게 전달.
