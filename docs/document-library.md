# 내 문서로 업무 자료 검색하기

1. 처음 한 번 `npm run setup:documents`를 실행한다. Python 3.10 이상이 필요하며 3.14에서 검증했다. 프로젝트 안의 `.venv-attachments`에 고정된 pypdf를 설치한다.
2. 서버를 시작하고 **내 문서 → 파일 선택 → 문서 넣기 · 내용 추출**을 누른다.
3. 추출 내용을 원본과 비교한다. PDF는 쪽, XLSX는 시트/셀, HWPX는 구역/XML 문단 위치를 표시한다. 원본은 목록에서 다시 내려받을 수 있다.
4. **내 문서 검색**을 눌러 파일 안에 실제로 있는 키워드를 검색한다. 로컬 AI 요약은 검색된 근거만 요약한다. 모델이 없어도 검색·원본 확인·금액 대조를 사용할 수 있다.
5. 엑셀의 단일 정수 셀 등 숫자 근거는 **초안 금액 대조에 선택**할 수 있다. 실제 원 단위 금액인지 확인한 후 본문 금액과 비교한다. 수식·합계·날짜·통화 의미를 자동 판정하지 않는다.

파일당 20 MiB, 최대 50개, 보관 원본 합계 200 MiB, 검색 색인 JSON 5 MiB 이내다. 같은 바이트의 파일은 중복 등록하지 않는다. 원본과 추출 결과는 `data/library/`에 별도로 저장하여 그룹웨어 JSON 교체나 정기 동기화가 덮어쓰지 않는다. 파일이 바뀌면 새 문서로 등록된다. 이전 파일 삭제는 사용자가 선택한다.

보관본 삭제 확인란과 삭제 버튼은 앱에 보관한 원본·색인을 제거한다. 업로드하기 전의 원래 파일은 변경하지 않는다. 파일 시스템 오류로 삭제 실패가 표시되면 재확인해야 한다. 다운로드 전 SHA-256을 대조하여 저장 후 변조된 원본은 제공하지 않는다.

이 목록은 단일 PC 사용자 소유 자료다. 그룹웨어 계정·조직 권한·현행 규정·시행 기간을 인증한 자료가 아니다. 공유 PC의 다른 로컬 사용자 접근을 차단하는 로그인 서버도 아니다. 직접 넣은 자료를 기관 공식 규정으로 단정하지 않는다.

스캔 PDF/OCR, 구형 HWP/XLS, 표 레이아웃 복원, 엑셀 수식 계산은 지원하지 않는다. PDF의 읽기 순서, 엑셀 날짜 원시값, 숨긴 시트 제외, HWPX의 실제 쪽 번호 부재를 추출 경고와 함께 확인한다. 파서 시간/파일 한도는 완전한 메모리 격리가 아니다.

실제 그룹웨어 자동 조회는 별도 미완료다. 내 문서 기능은 로그인된 브라우저의 내용을 자동 수집하거나 상신하지 않는다.
