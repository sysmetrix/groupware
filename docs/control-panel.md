# 로컬 AI · 업무 도우미 실행 관리자

바탕화면의 **Groupware AI Control**을 더블클릭한다. 콘솔 창 없이 실행된다.

녹색 전원 표시와 금색 AI 별을 조합한 아이콘을 실행 파일·창·바탕화면 바로가기와 웹 파비콘에 사용한다. Windows 아이콘은 16–256px의 7개 크기를 포함한다. 디자인 원본은 `public/favicon.svg`, Windows 생성 스크립트는 `scripts/build-control-icon.ps1`이다. 디자인 수정 시 둘의 도형을 맞춘 뒤 생성 스크립트와 설치 스크립트를 차례로 실행한다.

- **모두 시작**: 로컬 Ollama와 업무 도우미를 시작한다. 이미 관리 실행 중인 서비스는 유지한다.
- **시작 / 종료**: 각 서비스를 개별 제어한다.
- **업무 도우미 열기**: 실행 중인 앱을 기본 브라우저에서 연다.
- **모두 종료**: 앱과 모델 서버, 그 하위 모델 실행 프로세스를 종료한다. 파일은 삭제하지 않는다.
- **창만 닫기**: 관리 창만 닫고 서버를 유지한다.
- **모두 종료 후 닫기**: 두 서버 종료가 확인된 경우 관리 창도 닫는다.
- 창 오른쪽 위 **X**를 누르면 서버도 종료할지 선택한다.

업로드·저장 중에는 완료를 기다린 뒤 종료한다. 상태는 약 15초마다 확인하며, 명령 실행 동안 버튼을 잠가 중복 실행을 막는다. 모델 서버 시작은 서버의 준비를 의미한다. GPU에 모델을 올리는 것은 첫 AI 요청 때 이루어지며, 설치된 모델과 GPU 상태는 업무 도우미의 데이터 연결 화면에서 확인할 수 있다.

별도 터미널로 실행한 서버는 「별도로 실행됨」으로 표시하고 자동 종료하지 않는다. 원래 실행 창에서 종료한 다음 이 프로그램으로 시작한다. 포트 충돌·소유권 검증·프로세스 트리 관리는 [실행 관리 명령](runtime-control.md)을 사용한다. 이 프로그램은 그룹웨어 로그인이나 실제 업무자료 자동 수집을 추가하지 않는다.

## 다른 PC 또는 코드 업데이트 후 설치

Windows의 .NET Framework C# 컴파일러와 Windows PowerShell을 사용한다. 추가 GUI 패키지나 관리자 권한은 요구하지 않는다. 프로젝트의 앱 및 로컬 모델 설치를 먼저 완료한다.

```powershell
powershell -NoProfile -File scripts/install-control-panel.ps1
```

실행 파일은 `data/control-panel/GroupwareControl.exe`, 바로가기는 현재 사용자 바탕화면의 `Groupware AI Control.lnk`다. 프로젝트 폴더를 옮겼으면 다시 설치한다. 실행 파일만 별도 PC로 복사하면 안 된다. 소스는 `desktop/GroupwareControl.cs`로 GitHub에 공유하고, 실행 파일은 각 PC에서 생성한다. 코드 업데이트 후 관리 창을 닫고 설치 명령을 다시 실행하면 된다. 서버는 계속 실행해도 된다.
