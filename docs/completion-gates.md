2026-10-23 사용자가 새 작업 공간 재개를 승인했다. 공간 생성은 성공했으나 바로 다음 동일 공간 조회에서 `Task space does not exist`가 재현됐다. 로그인 실패나 사용자 승인 부족이 아닌 브라우저 공간 수명 오류로 실제 연결이 막혔다. 정상 요청·응답 계약과 기관 표본은 아직 확보하지 못했다. 별도로 화면에서 PDF/XLSX/HWPX를 직접 넣고 추출 내용·검색·원본·금액 대조를 사용하는 내 문서 흐름을 추가했다. 이 기능을 실제 그룹웨어 연결 완료로 간주하지 않는다.

브라우저 연결 오류를 새로운 작업 공간·다른 도구·추측한 API 호출로 우회하지 않는다. 실제 로그아웃/로그인은 사용 중인 작업을 끊으므로 사용자가 가능한 시점에 수행해야 한다. 서버 변경은 검증된 테스트 대상으로 시작하고 운영 문서를 임의로 저장·상신하지 않는다.
