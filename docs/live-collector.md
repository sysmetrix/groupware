# 실시간 읽기 전용 수집기 (v1.0.0, 2026-11-08)

로그인된 그룹웨어 화면 안에서 앱 자신의 서명 API 클라이언트를 재사용해 업무 목록을 직접 읽는다. 화면을 클릭하며 표를 긁던 기존 방식(메일 1~2초, 예산은 캔버스 선택 실패로 미완료 사례)과 달리 8개 영역을 **병렬로 약 0.3초**에 읽는다(2026-11-08 실측 269~298ms).

## 구성

| 파일 | 역할 |
|---|---|
| `src/live/collector.browser.js` | 브라우저(그룹웨어 페이지)에서 실행. `window.BWYFGW.collect()` |
| `src/live/briefing.mjs` | 순수 함수: 할 일 판정·기한 추출·지난 실행 대비 새 항목·HTML/Markdown·업무도우미 dataset 변환 |
| `scripts/live-report.mjs` | 수집 JSON → `data/live/latest.html·md·json`, `history/날짜.html`, `state.json`, `dataset.json` |
| `scripts/live-build.mjs` | `build/live/gw-live.js`(번들), `bookmarklet.txt`, `install.html`(북마크 설치 페이지) |
| `test/live.test.mjs` | 합성 자료 테스트 10개(허용 목록, 세션 만료, 모듈 격리, 데이터 계약, XSS 이스케이프 등) |

## 실행 방법

1. **원클릭(어느 PC든)**: `npm run live:build` 후 `build/live/install.html`을 열어 "GW 브리핑" 버튼을 북마크바로 끌어다 놓는다. 그룹웨어에 로그인한 화면에서 북마크를 누르면 새 탭에 브리핑이 열린다.
2. **Aside 자동 실행**: Aside 스킬 `bwyf-groupware-live`가 번들을 주입해 수집하고 `npm run live:report -- <raw.json>`으로 파일을 만든다. 평일 08:50 루틴 "그룹웨어 평일 아침 업무 브리핑"이 이 절차를 실행한다(이 PC와 Aside가 켜져 있어야 함).
3. **DevTools**: 그룹웨어 화면 콘솔에 `build/live/gw-live.js` 내용을 붙여 넣고 `await BWYFGW.collect()`.

업무도우미가 실행 중이면 `npm run live:report -- <raw.json> --import http://127.0.0.1:3210`으로 결재·공지·일정 목록을 가져온다(다른 범위의 실제 자료가 있으면 바꾸지 않음).

## 안전 장치

- 허용 목록 밖 경로는 요청 전에 `NOT_ALLOWED`로 거부한다. 출근 등록(`/human/openapi/commute/register`), 조회수 기록(`PutVisitStat`), 조회조건 저장(`iniWrite`) 같은 앱의 부수 쓰기도 호출하지 않는다.
- 쿠키·토큰·서명키 값을 읽지 않는다. 앱 클라이언트가 내부에서 서명한다. `https://gw.bwyf.or.kr` 밖에서는 실행되지 않는다.
- 제목·미리보기의 `비밀번호: …`, `pw=…` 같은 표현은 수집 단계에서 `[MASKED]` 처리한다.
- 모듈별로 실패를 격리한다. 세션 만료(`SESSION_EXPIRED`)면 `state.json` 기준선을 앞당기지 않는다.
- 결과 파일은 `data/`(Git 제외)에만 저장한다. `history`·`raw`는 60일 보관 후 정리한다.

## 판단 규칙 (briefing.mjs)

- 긴급: 내 결재 대기, 부서 접수 대기, 배부 대기, 반려·회수된 내 상신문서, 요청·제출·회신 등 행동 단어가 있는 받은메일함 안읽음.
- 보통: 발송 대기, 그 밖의 받은메일함 안읽음.
- 참고: 미열람 열람문서, 안 읽은 공지, 최근 3일 내 행동 단어가 있는데 회신·전달 기록이 없는 메일, 7일 내 휴가·외출.
- 광고·뉴스레터·웨비나 등은 메일 안읽음에서 제외한다.
- 제목의 `~11.20.`, `(~11/9(월) 16:00)`, `11월 20일까지`, `기한: 11/20`을 기한으로 읽어 D-day를 붙인다. 본문 기한은 읽지 않는다.

## 알려진 한계

- 일일 이상근태(결근대기·미인정) 행 API(`/personal/hpd0220/0hr00002`)는 요청 형식을 확정하지 못해 제외했다.
- 예산 개별 집행내역(원장 팝업 `/nonprofit/popup/0BN00001`)은 요청 형식이 달라 400이 반환돼 제외했다. 월간 예산 루틴은 누계를 이 수집기로, 개별 행은 화면으로 읽는다.
- 예산 기수는 `연도-2014`로 계산한다(2026년=12기). 재단이 기수를 바꾸면 `budgetGisu`로 지정한다.
- 그룹웨어 업데이트로 번들 구조나 응답 필드가 바뀌면 `CLIENT_NOT_FOUND` 또는 빈 값이 나올 수 있다. 이때는 화면 조작 시 앱이 보내는 요청을 다시 확인해 수집기를 고친다.
