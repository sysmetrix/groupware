# GW 통합 업무센터와 실시간 읽기 전용 수집기 (v2.0.0, 2026-11-08)

로그인된 그룹웨어 화면 안에서 앱 자신의 서명 API 클라이언트를 재사용해 업무 자료를 직접 읽고, **한 화면(업무센터)**에서 확인·검색·처리까지 이어 가도록 만든 도구다. 수집은 8개 영역을 병렬로 약 0.3초(2026-11-08 실측 269~298ms)에 끝낸다.

## 구성

| 파일 | 역할 |
|---|---|
| `src/live/collector.browser.js` | 그룹웨어 페이지에서 실행. `BWYFGW.collect/search/budgetProject/budgetLedger/attendanceDays/routingHistory/submittedRange`, 원래 화면 링크(`links`) |
| `src/live/briefing.mjs` | 순수 함수: 할 일 판정, 제목·본문 기한 추출, 근태 이상, 배부·접수 추천, 주간 실적 초안, CSV, HTML/Markdown, 업무도우미 dataset |
| `src/live/workcenter.browser.js` | 통합 업무센터(전체 화면, Shadow DOM). `open()` 전에는 페이지에 아무것도 붙이지 않는다 |
| `scripts/live-build.mjs` | `build/live/gw-live.js`(번들), `bookmarklet.txt`(설치), `bookmarklet-mini.txt`(실행), `install.html` |
| `scripts/live-report.mjs` | 수집 JSON → `data/live/latest.html·md·json`, `history/`, `state.json`, `dataset.json` |
| `test/live.test.mjs` | 합성 자료 테스트 18개 |

## 업무센터 화면

| 메뉴 | 내용 |
|---|---|
| 오늘 할 일 | 결재 대기·부서 접수·배부·발송 대기, 반려·회수된 내 문서, 안 읽은·회신 확인 메일, 공지, 근태 이상, 예정 휴가를 긴급→보통→참고로 한 목록. 영역 필터, 목록 내 찾기, 새 항목, 완료 표시, 내일까지 미루기 |
| 결재·문서유통 | 6개 목록과 메뉴 15종 건수. 배부 대기에는 **배부 추천 부서**, 부서 접수 대기에는 **접수 추천 담당자**(최근 180일 처리 이력 500건 기준, 지난 동시 배부 패턴 포함) |
| 메일 | 최근 100통 + 내 메일함 안읽음, 안 읽음·회신 확인·첨부 필터, 본문까지 서버 검색 |
| 통합검색 | 결재문서 본문, 메일 본문 일부, 게시판, 첨부파일, 일정, 인물, 연락처를 한 번에(검색어는 그룹웨어 최근 검색어에 남기지 않음) |
| 예산 집행 | 프로젝트 누계(관·항·목·세), 집행 저조·소진 임박·초과 표시, 세목 클릭 → 결의 내역과 집행액 대조, 문서번호 → 결재문서 바로 열기, CSV |
| 근태·연차 | 오늘 출퇴근, 이번 달 시간, 일별 근태(이상일 강조), 연차 잔여·사용 내역, 근태신청 화면 열기 |
| 일정·기한 | 그룹웨어 캘린더, 휴일, 내 휴가, 제목·본문에서 찾은 기한, 내 할 일을 날짜별로 |
| 내 할 일 | 어느 항목에서든 "할 일 추가", 본문 기한으로 기한 자동 입력 |
| 보고서 | 오늘 브리핑 HTML 저장·Markdown 복사, 할 일 CSV, **주간 업무 실적 초안**(최근 7일 상신·접수) |
| 설정 | 자동 새로고침(기본 5분), 새 긴급 항목 바탕화면 알림, 예산 조회 대상, 내 긴급 키워드, 초기화 |

**처리 창**: 항목을 고르면 오른쪽에 요약·추천·기한이 나오고, "여기서 열기"를 누르면 그룹웨어 원래 결재문서·게시글·근태신청 화면이 같은 페이지에 열린다. 결재·접수·배부·발송은 그 화면의 원래 버튼으로 처리한다. 열린 문서 본문에서 기한·요청 문장·붙임을 자동으로 찾아 보여 주고 할 일로 넣을 수 있다.

단축키: `j`/`k` 이동, `Enter` 처리 창에 열기, `o` 새 창, `x` 완료, `s` 미루기, `/` 검색, `r` 새로고침, `1`~`9` 메뉴, `Esc` 닫기, `Alt+G` 업무센터 열기·닫기.

## 설치와 실행

1. `npm run live:build` 후 `build/live/install.html`을 연다. **GW 업무센터 설치**와 **GW 업무센터** 버튼을 북마크바로 끌어다 놓는다.
2. 그룹웨어에 로그인한 화면에서 **설치** 북마크를 한 번 누르면 업무센터가 열리고 이 브라우저(그룹웨어 저장소)에 저장된다. 이후에는 1KB짜리 **GW 업무센터** 북마크로 연다. 새 버전은 설치 북마크를 다시 끌어다 놓고 한 번 누른다.
3. Aside에서는 스킬 `bwyf-groupware-live`로 번들을 주입하고 `BWYFGW_WC.open()`을 호출한다. 평일 08:50 루틴 "그룹웨어 평일 아침 업무 브리핑"은 화면을 열지 않고 수집·추천·파일 보고서를 만든다.

## 안전 장치

- 허용 목록 밖 경로는 요청 전에 거부한다. 출근 등록, 조회수 기록(`PutVisitStat`), 조회조건 저장(`iniWrite`), 검색어 저장(`gw018A04`·`gw032A01`)을 호출하지 않는다.
- 쿠키·토큰·서명키 값을 읽지 않는다. `https://gw.bwyf.or.kr` 밖에서는 실행되지 않는다. 제목·미리보기·검색 조각의 비밀번호 표현은 `[MASKED]` 처리한다.
- 업무센터의 완료 표시·미루기·할 일·설정·추천 이력 캐시(12시간)는 이 브라우저의 그룹웨어 저장소(localStorage)에만 둔다.
- 처리 창에서 원문을 열면 그룹웨어 규칙대로 열람 처리된다. 미열람 문서·게시글에는 경고를 표시한다.

## 알려진 한계

- 메일 원문은 내장하지 않고 메일함 화면을 연다(메일 팝업 인자가 객체라 주소로 열 수 없음).
- 배부·접수 추천은 이력 통계다. 새 유형 문서나 조직 개편 직후에는 맞지 않을 수 있다.
- 통합검색은 그룹웨어 색인 범위·권한을 따른다. 아직 색인되지 않은 최신 문서는 나오지 않을 수 있다.
- 자동 새로고침·알림은 업무센터를 연 그룹웨어 탭이 열려 있는 동안만 동작한다.
- 예산 기수는 `연도-2014`로 계산한다. 그룹웨어 업데이트로 번들 구조나 응답 필드가 바뀌면 `CLIENT_NOT_FOUND`나 빈 값이 나올 수 있다.
