# GW 비서 업무센터 안내

버전마다 바뀐 점은 GW 비서의 업데이트 내역과 GitHub 릴리스에 있다. 이 문서는 화면과 동작을 설명하며, 절 제목의 버전은 그 내용이 들어온 때다.

## 자료 보호 (v0.38)

- 다중 탭: 변경분을 합치고 삭제·설정 변경을 동기화합니다. 주간 보고 충돌본은 보고서의 **보관 초안 복구**에서 되돌릴 수 있습니다. 저장 실패는 성공으로 표시하지 않습니다.
- 계정 전환: 문서 추가 페이지·검색·근태·예약 캐시와 되돌리기를 비웁니다. 이전 계정의 늦은 응답은 반영하지 않습니다.
- 결재 더 보기: 중복 클릭 잠금, 문서 중복 제거, 새로고침 시 캐시 초기화.
- 자동 입력: 작성 중인 본문·신청서를 덮어쓰기 전에 확인하며 취소하면 필드에 쓰지 않습니다.
- 배포: 같은 소스는 같은 검증값을 만들고, 재빌드 시 기존 관리자 정책을 보존합니다. 테스트는 임시 출력 폴더를 사용합니다.


**v4 주요 변경**: 화면 디자인 시스템(src/live/wc.css)과 17개 모듈(src/live/wc/)로 재구성. 상태 기반 판정(기한 지남·급함·할 일·확인 필요·끝났는지 확인·기다리는 중·참고)과 단일 숫자 기준(summary.mine: 모든 배지·요약·브리핑·인쇄가 같은 숫자를 씀). 메일 일반·대용량 첨부 바로 받기(/mail/mail002A37, 대용량 링크)와 그룹웨어 문서 뷰어 미리보기(HWP·엑셀 등). 예산은 재단 15개 사업(SPJT_CODE)과 단위사업(항)을 이름으로 골라 '내 관심 사업'으로 저장·전환. 근태는 사실만 표시하고 신청 없는 결근에만 '정상입니다'(그룹웨어 기록 불변 고지, 3일 뒤 재표시), 신청 진행 중은 '기다리는 중'으로 분리. 크롬·엣지 확장 프로그램 패키지(uild/live/extension, Manifest V3 world: MAIN) 함께 생성.

로그인된 그룹웨어 위에 띄워 쓰는 **한 화면 GW 비서**다. 그룹웨어 앱이 쓰는 조회 API로 8개 영역을 약 0.3초에 읽고, 오른쪽 처리 창에 그룹웨어 **원래 화면**(결재문서, 배부·접수, 답장 쓰기, 새 기안, 근태신청)을 열어 그 자리에서 처리한다. 일반 기안·신청 자동 입력은 상신 전에서 멈춘다. 자원 예약만 확인된 내용으로 사용자 최종 확정 시 등록하며 취소·변경은 하지 않는다.

독립 검토자 평가(v2 48점 → v3.0 69점)의 지적을 반영해 v3에서 화면을 다시 만들고, v3.1에서 남은 문제(작성 중 내용 보호, 연속 처리 결과의 정직한 집계, 판단 규칙 교정)를 고쳤다.

## 사용 기록과 자료 이상 알림 (v0.79)

- **사용 기록**: 설정 → 관리·진단 → 사용 기록. 어떤 화면·버튼·비서 기능을 며칠에 몇 번 썼는지 이름과 횟수만 이 브라우저에 60일 동안 남긴다. 제목·본문·사람 이름·검색어·질문 내용은 적지 않고 어디로도 보내지 않는다. 파일로 내보내기, 복사, 끄기, 지우기를 할 수 있다. 계산은 `src/live/usage.mjs`, 화면은 `src/live/wc/40-usage.js`. 이름 규칙(영문·숫자·밑줄)에 맞지 않는 값은 저장 단계에서 버린다.
- **자료 이상 알림**: 그룹웨어가 업데이트되어 응답 모양이 바뀌면 조회는 성공인데 제목·날짜가 빈 줄이 들어온다. 읽은 자료에서 그런 흔적(꼭 있어야 하는 값이 대부분 비었거나, 몇 건 있다는데 한 줄도 못 읽음)을 찾으면 화면 위에 "그룹웨어 화면이 바뀐 것으로 보입니다"라고 알리고 진단에 자세히 적는다. 해당 영역을 끄지는 않는다. 판정은 `src/live/contract.mjs`. 실제 그룹웨어 자료로 잘못 울리는지는 아직 확인하지 못했다(지어낸 자료와 단위 테스트로만 확인).
- **대신 하지 않는 일**: 결재 승인·반려, 상신, 삭제를 시키거나 다른 직원의 시간외를 물으면 비서가 하지 않는 일이라고 바로 알린다. AI에 넘기지 않는다.

## 둘러보기 (로그인 없이 화면 보기)

`npm run live:demo` 를 실행하고 <http://127.0.0.1:3220> 을 열면, 지어낸 자료로 채운 GW 비서가 뜬다. 처음 써 보는 사람에게 보여 주거나, 화면을 고친 뒤 눈으로 확인할 때 쓴다.

- 실제 번들과 같은 방법으로 조립하되 수집기만 `src/live/demo/demo-collector.browser.js` 로 바꾼다. 그룹웨어에는 아무 요청도 보내지 않는다(네트워크 API를 쓰지 않는지 `test/live-demo.test.mjs` 가 검사한다).
- 기관·사람·문서·금액은 모두 지어낸 것이고 날짜는 오늘 기준으로 만들어진다. 머리글에 "둘러보기 · 지어낸 자료" 표시가 붙는다.
- 처리 창에는 그룹웨어 원래 화면 대신 안내 화면이 뜬다. 자원 예약은 그 탭의 메모리에만 남고, 첨부 받기처럼 실제 그룹웨어가 필요한 기능은 "둘러보기에서는 할 수 없습니다"라고 알린다.
- 숨기기·할 일·설정은 둘러보기 주소(127.0.0.1:3220)의 브라우저 저장소에만 남아 실제 사용 기록과 섞이지 않는다.
- 소스를 고친 뒤에는 새로고침만 하면 다시 조립된다. 파일만 만들려면 `node scripts/live-demo.mjs` (결과: `build/demo`).

## 화면 디자인과 움직임 (v0.70 차분한 작업 화면)

회색 바탕 위에 흰 작업지 한 장을 올려 둔 화면이다. 머리글과 왼쪽 메뉴는 바탕(`--bg`)에 녹아 있고, 본문과 처리 창만 흰 종이(`--card`)로 떠 보인다. 색은 세 가지 역할만 쓴다.

| 색 | 토큰 | 쓰는 곳 |
|---|---|---|
| 잉크 | `--pri`, `--pri-fg` | 이 화면의 주된 버튼 하나(새로 만들기, 하나씩 처리, 보내기). 어둡게 화면에서는 흰 버튼 |
| 파랑 | `--accent`, `--sel` | 고른 것과 링크(현재 메뉴 아이콘, 고른 줄, 달력의 오늘, 내 할 일 건수) |
| 빨강 | `--hi` | 급한 것. "급함"은 옅은 빨강 알약이다 |

- 진한 버튼은 화면마다 하나만 둔다. 목록·표·안내 상자 안에서 줄마다 되풀이되는 주 버튼은 옅은 파랑(`--accent-soft`)으로 낮춘다.
- 홈(v0.71)은 같은 내용을 한 곳에만 둔다. 왼쪽은 인사 → **지금 가장 먼저 할 일**(이어서 볼 일 2건) → 숫자 한 줄 → 비서 대화, 오른쪽은 오늘 일정(하루 띠 + 목록 + 자리 비움) · 챙겨 둘 것 · 자동화 · 자원 예약이다. 비서의 첫 인사는 숫자를 되풀이하지 않는다.
- **업데이트 내역 줄이기(v0.74)**: 번들에는 최근 12개 버전만 바뀐 점 목록을 싣고 그 이전은 제목만 싣는다(`trimChangelog`, `scripts/live-build.mjs`). 소스(`briefing.mjs`)와 GitHub 릴리스에는 전부 남는다. 내역 한 줄에 한 버전이라는 모양은 `npm run bump`가 지킨다.
- **자동 업데이트(v0.73)**: `autoUpdate`가 10분마다(그리고 탭으로 돌아올 때) 배포 사이트를 확인해 새 묶음을 미리 받아 SHA-256을 대조한다. 업무센터가 닫혀 있으면 바로 바꾸고, 열려 있으면 닫는 순간이나 다음에 열 때 바꾼다(쓰는 중에는 바꾸지 않는다). 같은 묶음은 한 탭에서 한 번만 시도한다. 설정의 "자동 업데이트"(`settings.autoUpdate`)나 정책 `updateCheck`로 끌 수 있고, 둘러보기에서는 동작하지 않는다.
- **확장 프로그램(v0.73)**: 시작 페이지의 `gw-bisu-extension.zip`을 한 번 설치하면 다시 설치하지 않는다. `mount.js`는 자동 업데이트가 브라우저에 받아 둔 묶음(Cache Storage `bwyfgw-wc`, 표지 `localStorage['bwyfgw:wc:auto']`)이 함께 설치된 것보다 새롭고 해시가 맞으면 그것으로 시작한다. 그룹웨어 화면을 20초 안에 알아보지 못해도 버튼은 띄운다. 버튼과 스타일이 문서에서 떨어져 나가면 2초 안에 다시 붙인다(`fabKeep`).
- **업데이트(v0.71)**: 새 버전 확인은 배포 사이트의 `current.json`(`version` 포함)을 먼저 보고, 읽지 못하면 GitHub 릴리스로 확인한다. 업데이트 내역의 "지금 바꾸기"(`updateNow`)는 북마크 "GW 비서 열기"와 같은 절차(버전 정보 → 실행 파일 → SHA-256 대조 → 실행)를 사용자가 누를 때만 밟는다. 둘러보기와 `updateCheck` 정책이 꺼진 곳에서는 동작하지 않는다. 새 버전은 `npm run bump -- 0.72.0 "제목" "바뀐 점"`으로 준비하고, main에 합쳐지면 배포와 GitHub 릴리스가 자동으로 만들어진다.
- **구글 동기화의 캘린더 연결(v0.71)**: 근태·기한을 올릴 캘린더는 ① 동기화 화면의 "올릴 캘린더"에서 고른 것(`settings.gcal.layers`) ② 이름이 비슷한 것("근태", "BWYF근태" 등) 순서로 정한다. 등록만 하고 이름을 적지 않아도 ①로 연결된다.
- 왼쪽 메뉴는 묶음(매일 보는 것 / 업무 / 자료 / 조직)으로 나뉘고, 머리글의 메뉴 버튼(`data-act="navMini"`)으로 아이콘만 남게 접는다. 접은 상태는 `settings.navMini`로 이 브라우저에 남고, 건수는 점으로 줄어든다. 너비는 `--navW` 하나로 정한다.
- 모양은 `src/live/wc.css` 한 파일에 있으며 studio 구역이 마지막에 놓인다. 색을 바꾸려면 이 파일의 studio 구역 토큰을 고친다(밝게·어둡게 두 묶음).
- 홈의 **하루 띠**는 8~19시를 한 줄로 놓고 오늘 일정과 내 부재를 칸으로, 지금 시각을 바늘로 보여 준다. 위치 계산은 `R.homeDayRail`(순수 함수, `home-model.mjs`), 바늘은 30초마다 움직인다.
- 움직임은 `src/live/wc/39-motion.js`가 맡는다. 화면 코드를 고치지 않고 그려진 결과를 지켜보다가 `.m-view`(화면 전환 직후 한 번), `.m-pane`(처리 창 열림), `.m-theme`(밝게·어둡게), `.m-bump`(메뉴 건수 변화), `.m-tick`(숫자 변화) 클래스만 붙인다.
- 자동 새로고침으로 같은 화면이 다시 그려질 때는 움직이지 않는다. 컴퓨터의 "움직임 줄이기" 설정이 켜져 있으면 모든 움직임을 끈다.
- 둘러보기에서 `http://127.0.0.1:3220/?at=13:20` 처럼 시각을 붙이면 그 시각인 것처럼 보여 주어, 근무 시간 밖에도 하루 띠를 확인할 수 있다.

## 대화형 기능

- **연속 처리 모드**: 처리할 항목을 차례로 연다. 문서는 "처리했음"을 누르면 목록을 200건까지 다시 읽어 실제로 처리됐는지(✓) 아직 남았는지 확인하고, 메일은 "답장했음"을 누르면 보낸메일함에서 같은 제목의 답장을 찾는다. 연속 처리를 시작한 뒤 보낸 답장만 "처리 확인"으로 숨기고, 그 전 답장은 "이전 답장만"으로 남겨 둔다. 근태·공지는 "직접 확인"으로 따로 센다. 읽지 않은 문서·게시글·메일은 자동으로 열지 않고 "열면 읽음으로 기록됩니다"를 먼저 보여 준다. 확인 중에는 버튼을 잠근다.
- **작성 중 보호**: 처리 창(답장·결재 의견·기안)에 입력한 뒤 다른 항목으로 옮기거나 닫으면 먼저 묻는다. 입력·선택(change)·붙여넣기를 감지한다. 다시 로그인도 입력 중이면 묻는다. 메일은 그룹웨어 설정에 따라 임시보관함에 자동 저장될 수 있다(기본 3분). 근태신청처럼 그룹웨어 전체 화면은 처리 창을 자동으로 넓게 열고, 왼쪽 메뉴를 누르거나 팝업 화면을 열면 원래 폭으로 돌아간다.
- **명령 팔레트** `Ctrl+K`: "배부", "A201", "지난달 근태", "새 메일", "전략경영실-1234"(문서번호 찾아 열기), 양식 이름, 할 일 제목으로 바로 이동·실행한다.
- **되돌리기**: 숨기기·미루기·보드 이동·기한 변경·할 일 삭제는 알림의 "되돌리기"나 `Ctrl+Z`로 취소한다.
- **처리 창**: 너비를 끌어 조절하고 "크게"로 넓힌다. 자동 새로고침은 열린 원문을 다시 불러오지 않으며, 입력 중이면 "새 자료 반영" 띠만 띄운다.
- 단축키는 한글 입력 상태에서도 동작한다(`e.code` 기준). 목록 내 찾기는 한글 조합이 끊기지 않게 목록만 다시 그린다.

## 판단 규칙 (briefing.mjs)

- **점수**: 기본 점수(결재 대기 62, 부서 접수 50, 배부 48, 발송 34, 반려 70, 기한 메일 44, 근태 확인 30~48, 휴가일 마감 85 등) + 기한 임박(오늘·지남 +40, D-1 +34, D-3 +24, D-7 +12) + 대기(근무일 3일 이상 +22, 그 전 하루 +4) + 긴급 표현(+20) − 홍보·안내성(−22). 70점 이상이 긴급이며 **최대 6건**, 40점 이상 보통, 나머지 참고. 같은 점수면 오래된 순.
- **회신 메일**: "Re:/FW:" 메일은 내 기한으로 보지 않고, 안 읽었을 때만 "내 요청에 온 회신"(참고)으로 둔다.
- **기한**: 제목·메일 미리보기(엄격 모드: ~·까지·기한·마감만)·원문 본문에서 "~11.20.", "11/9(월) 16:00", "11월 20일까지", "기한: 11/20"을 시간까지 읽는다. 기간 표현(11.10.~11.20.)은 끝 날짜를 기한으로 본다. 답장한 기한 메일은 "보통 · 제출까지 끝났는지 확인"으로 낮춘다. 휴가일 마감은 별도 줄 대신 원래 항목에 "⚠ 휴가일 마감 · 11-06까지" 표시로 붙인다. 실제 마감은 휴가 전 마지막 근무일(주말·다른 휴가일 제외)로 계산하고, 점수를 더한다(미답장 +24, 답장 +4).
- **휴가일 마감**: 기한 날이 예정된 휴가와 겹치면 맨 위에 "전날까지 처리" 항목을 만든다.
- **근태 확인**: 결근·지각·조퇴·미인정 중 승인된 신청이 없는 날. 결재 끝난 하루 휴가, 휴일, 18시 전의 오늘은 빼고, 근무일대체 하나는 7일 안의 가장 가까운 결근 하루만 "연결된 날일 수 있음"으로 설명한다. "결근"으로 단정하지 않고 "확인 필요"로 표시한다.
- **배부·접수 추천**: 제목 단어를 흔할수록 낮게 치는 가중치(IDF)로 비교하고 지역 공통어(부천·경기도·재단 등)와 문서의 발송기관·부서·발신자 이름, "…센터/재단/협의회/교육지원청" 같은 기관어는 뺀다. 의미 있는 단어가 겹치는 지난 문서만 근거로 쓴다(발송처만 같은 것은 제외). "비슷한 n건 중 k건"으로 보여 주고, 3건 이상 중 절반 이상일 때만 "높음"이다.

## 설치

1. `npm run live:build` → `build/live/install.html`에서 **GW 비서 설치**와 **GW 비서** 두 북마크를 북마크바로 끌어다 놓는다.
2. 그룹웨어 화면에서 **설치**를 한 번 누르면 GW 비서가 열리고 이 브라우저에 저장된다. 이후에는 2KB **GW 비서** 북마크로 연다. 실행 북마크는 저장된 코드의 SHA-256을 확인하므로, 저장본이 바뀌었거나 다른 버전이면 실행하지 않고 재설치를 안내한다. 새 버전은 두 북마크를 다시 끌어다 놓는다.
3. Aside에서는 스킬 `bwyf-groupware-live`로 번들을 주입하고 `BWYFGW_WC.open()`을 호출한다. 평일 08:50 루틴은 화면 없이 수집·추천·파일 보고서를 만든다.

## 안전 장치

- 허용 목록 밖 경로는 요청 전에 거부한다. 출근 등록, 조회수 기록, 조회조건 저장, 검색어 저장 API는 호출하지 않는다.
- 쿠키·토큰·서명키 값을 읽지 않는다. 비밀번호 표현은 `[MASKED]` 처리한다. CSV는 수식 실행을 막는다(`=`, `+`, `-`, `@` 앞에 `'`). 브리핑 미리보기는 스크립트가 막힌 sandbox iframe이다.
- 메일 본문(v0.80.0)은 보낸 사람이 만든 HTML 그대로 보여 주되, 스크립트와 같은 출처 권한이 없는 sandbox iframe(`allow-popups allow-popups-to-escape-sandbox`)에만 싣는다. 문서 머리에 자체 CSP(`default-src 'none'`, 그림과 인라인 스타일만 허용)를 넣고, 태그 정리(`mailBodyDoc`)는 두 번째 겹이다. 그룹웨어에 저장된 본문 그림(`/mail/mail002A30`, 서명·붙여 넣은 그림)만 로그인으로 읽어 data 주소로 넘기고, 다른 서버의 그림은 그룹웨어 메일 화면과 마찬가지로 틀 안에서 바로 불러온다(안 읽은 메일은 사용자가 읽음 처리에 동의한 뒤에만 본문을 읽는다). `mailDetail()`의 `html`·`plain`은 화면 표시 전용이며 AI·저장소·기록에는 가려진 `text`만 쓴다.
- 미열람 문서를 처리 창·새 창으로 열 때와 연속 처리 시작 때 열람 기록이 남는다고 먼저 묻는다.
- 숨기기·미루기는 개인 표시이며, 숨긴 항목이 하루 넘게 그룹웨어에 남아 있으면 "숨겼지만 아직 남음"으로 다시 보여 준다. 읽지 못한 영역은 카드에 "확인 불가"로, 세션 만료는 상단 띠와 "다시 로그인" 버튼으로 알린다.
