# 검증 기록과 수동 절차

## 자동 검사

`npm run check`는 소스·프런트엔드·테스트의 JavaScript 문법을 검사한다. `npm test`는 Node 내장 러너로 다음을 검증한다.

- 사용자·조직 필터 및 빈 ACL의 접근 거부
- 완료 결재 제외, 기한 경과, 한국시간 날짜 경계
- 진행 중 일정 포함, 종료·취소·완료 일정 및 7일 경계 제외
- 만료·미시행 문서 제외, 근거 없음 응답
- 중복 ID·민감 추가 필드·잘못된 날짜·위험한 링크 거부
- 금액 형식·정확한 금액 대조·필수 입력·첨부 미확인
- 모델 요청의 제한된 근거, 모의 응답의 출처 ID 검증, 모델 실패
- 실제 loopback HTTP 서버의 정적 파일·작업·가져오기·실행 기록
- CSRF·교차 출처 요청 차단, 잘못된 JSON과 content type
- 검색어·문서 본문을 감사 기록에 남기지 않음
- CSV/TSV 인용·개행·머리글·타입·출처 검사
- 자동 파일 확인의 사용자·조직·시각 검사, 오류 시 기존 스냅샷 보존
- 한국 시간 정기 브리핑, 날짜 변경, 중복·동시 실행, 재시작 후 보고서 복원
- 자료가 바뀌거나 만료되면 이전 보고서 제공 거부
- 재시작 직후 입력 미검증·입력 파일 누락 시 저장된 보고서 제공 거부
- 유효 시간 이내의 과거 파일 덮어쓰기 차단, 수정 후 복구
- 일시적 IO 오류의 120/240초 재확인과 복구 후 기본 주기 복귀
- 실행 중 중지·재시작 시 단일 타이머 유지
- 보고서 완료 감사 실패 시 제공 보류 및 다음 실행에서 재시도
- 실행 ID·오류 코드 보존, 원시 오류·본문 누락, 같은 실패 연속 기록 억제

2026-10-22 후속 구현판은 로컬 Node 24/Windows에서 문법 검사와 Node 테스트 68개와 첨부용 Python 테스트 9개를 통과했다. 첨부 검증은 합성 파일과 CLI→검색까지이며 실제 기관 표본·브라우저 시각·LLM 추론은 포함하지 않는다. [첨부 검증 절차](attachments.md)를 참고한다. 수집 기반의 신규 9개 테스트는 빈 중간 페이지·부분 수집·중복·체크포인트·범위·삭제·ACL 회수·파일 게시 실패를 검사한다. GitHub Actions 설정은 Ubuntu/Windows를 대상으로 하며 해당 커밋의 결과는 [실행 기록](https://github.com/sysmetrix/groupware/actions)에서 확인한다. 실제 LLM 추론·그룹웨어 API 연결·브라우저 렌더링은 자동 테스트 범위 밖이다. 타이머 간격은 주입한 타이머로 검증했고 실제 수분 대기 부하 시험은 아니다.

## 브라우저 검증 상태

초기 Windows Computer Use는 URL 판별 오류로 중단됐다. 이후 실제 그룹웨어 홈·전자결재 HOME·미결 탭을 제한적으로 관찰했다. 이번 후속 작업에서는 사용자 확인으로 새 공간을 생성해 로컬 앱의 합성 브리핑·검색·근거 없음·100원 금액 차이·기록 최소화·일부 Tab 포커스를 확인했다. 검색 화면의 390/768/1440px DOM 가로 넘침도 없었다. 스크린샷·다운로드 이벤트 시간 초과 후 같은 공간이 제어 해제를 반환하여 중단했다. 전체 시각 검증·브라우저 E2E 완료는 아니다. 다음 목록은 반복 가능한 수동 절차이며 아직 남은 항목은 [후속 검증 표](followup-verification.md)로 구분한다.

1. `npm start` 후 `http://127.0.0.1:3210` 접속. 합성 예제/실시간 미연결 표시와 4개 현황 카드 확인.
2. 브리핑 새로고침 후 원문 없는 예제가 허위 링크를 표시하지 않는지 확인.
3. 문서 검색에서 `운영계획` 입력. 유효한 예제 문서가 보이고 만료 예제가 제외되는지 확인.
4. `찾을수없는키워드`를 검색해 근거 없음 확인.
5. 초안에서 본문 1,000원·첨부 900원을 입력하고 100원 불일치 확인. 숫자/날짜 오류 확인.
6. 예제 JSON 다운로드, 데이터 교체 확인란, 가져오기 성공·오류 확인. 실제 자료를 테스트에 사용하지 않음.
7. 실행 기록에 작업만 남고 입력한 본문·검색어가 없는지 확인.
8. 390px·768px·1440px 화면, 키보드 Tab, 포커스 표시, 한국어 줄바꿈 확인.
9. 로컬 모델을 별도 설정한 환경에서 요약과 원문 출처를 대조하고, 모델 중단 시 근거만 유지되는지 확인.

## 운영 전 조건

실제 그룹웨어 연동의 권한·페이지 완전성·문서 버전·조회 부작용은 `live-integration.md`를 따라 검증한다. 로컬 스냅샷 파일의 ACL 값은 서버 권한 검증의 대체 수단이 아니다.

다른 PC 설치·업데이트 스크립트는 기존 설정을 보존한다. Windows 임시 작업 등록·주체·로그온 트리거·Start-ScheduledTask로 실제 서버 실행·HTTP 응답·제거까지 검증했다. 실제 로그아웃/로그인은 수행하지 않았다. `scripts/windows-verify-autostart.ps1`로 대상 PC에서 재현할 수 있다. 로컬 모델은 미설정이며 `npm run doctor:model`로 확인한다. 실제 그룹웨어 커넥터는 미구현이다. [브라우저 진단](browser-recovery.md)과 [수집 계약](sync-contract.md)을 참고한다.
