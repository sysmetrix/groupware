# GW 비서 성공 기준 (실사용 및 자동 검증)

- 문장·표·간단 요약 등 형식 요청을 준수하고 직전 대화의 대상·기간·지시를 이어간다.
- 일정·메일·결재·근태·예산·업무 항목을 실제 조회하며 확인 범위와 실패를 정확히 표시한다.
- 구글 캘린더는 별도 읽기 권한이 없는 경우 조회를 주장하지 않는다. 연결한 경우 선택한 계정과 범위를 표시한다.
- AI가 도구를 스스로 선택하더라도 사용자 의도 밖의 읽기·쓰기 및 개인정보 유출을 방지한다. 전송 전 외부 전송 범위가 안내되어야 한다.
- 신청·예약·발송·삭제 등은 표시된 확인 경로를 거치며, 작업 완료를 허위로 주장하지 않는다.
- 중지·실패·할당량 소진·재시도·새 대화·다른 사용자 전환에서 상태와 기록이 일관되어야 한다.
- 단위, 통합, 보안 회귀 및 실제 브라우저·실제 Gemini 동작을 확인한다. 미지원이나 승인 대기는 완료로 간주하지 않는다.
- (v0.86.0) "뭐부터"에는 먼저 할 일과 근거(기한·결재 차례·요청 메일·받은 날)를 답하고, 목록만 나열하지 않는다.
- (v0.86.0) 특정 메일의 내용·요청을 물으면 그 메일 한 통만 읽어 원문 문장으로 정리한다. 안 읽은 메일은 읽음으로 바뀐다는 확인을 먼저 받는다. 외부 AI 정리·답장 초안은 별도 동의(설정: 매번 묻기·항상·끄기) 뒤에 가린 본문만 보내고, 본문에서 나온 내용은 대화 기록에 저장하지 않는다.
- (v0.86.0) "그거·그 메일·2번 메일"은 직전 대화에서 다룬 메일로 이어 받고, 대상이 없으면 고르게 한다. 회신 요구 문장과 협조·홍보 요청을 구분한다.
- (v0.86.0) 실사용 질문은 eval/chat-questions.json 의 '이해' 분류로 회귀 검사한다.
