이 후속 검증 시점의 자동 테스트는 60개였다. 이후 [첨부 추출·검색](attachments.md)을 추가해 현재 Node 68개·Python 9개를 통과했다. 브라우저 확인은 이미 실행 중인 로컬 서버의 합성 자료로 수행했다. 최신 수집 모듈은 별도의 단위·파일 통합 테스트로 검증했다.

## 브라우저 한계

사용자의 새 공간 재개 확인 후 같은 공간에서 여러 라운드의 DOM 조회·폼 입력이 성공했다. 스크린샷은 `Page.captureScreenshot` 시간 초과, 합성 예제 다운로드 이벤트도 10초 시간 초과가 발생했다. 다운로드 자체의 실패로 단정하지 않으며 파일 가져오기까지 검증한 것으로 표시하지 않는다.

이후 같은 공간 조회에서 `no longer assigned / hard stop`이 반환되어 브라우저 조작을 중단했다. 새 공간이나 다른 도구로 우회하지 않았다. 실제 그룹웨어 이동 전에 중단됐으므로 이번 실행의 새로운 운영 화면·API 근거는 없다.

## 다른 PC에서 재현

```powershell
npm run check
npm test
npm run demo:sync
npm run sync:pages -- data/sync-demo/pages.json data/sync-demo/scope.json data/sync-demo/state.json data/sync-demo/dataset.json
powershell -NoProfile -File scripts/windows-verify-autostart.ps1
npm run doctor:model
```

Windows 검증은 분리된 합성 폴더에 서버를 복사하고 임시 작업을 등록·실행·제거한다. 기존 서버·자료·자동 실행 작업을 교체하지 않는다. 테스트 폴더는 `data/`에 남긴다. 조직 정책의 등록 거부를 우회하지 않는다. 실제 로그아웃은 수행하지 않는다.

`doctor:model`은 모델 미설정·부재를 종료 코드 2로 구분한다. 설정된 모델이 있으면 [Ollama 모델 목록 API](https://docs.ollama.com/api/tags)로 로컬 목록을 확인하고, `--probe`를 주면 합성 근거만으로 추론의 출력 형식·출처 ID를 검사한다. 모델을 설치·다운로드하지 않으며 의미적 정확성을 자동 판정하지 않는다.

## 공식 자료와 중복 검토

더존 [ONE AI 주요 프롬프트 모음집](https://www.douzone.com/html/event/250417/data/Amaranth%2010%20ONE%20AI%20Prompt%20Guide.pdf)은 회계·인사·예산·UC 등 모듈별 활용을 다룬다. 범용 요약·문서 작성·업무 질의는 내장 기능과 겹칠 가능성이 있으므로 기관에서 사용 가능한 기능을 비교해야 한다. 제품 설명은 기관 도입·활성화 증거가 아니다.

공식 고객센터의 [근태리더기 연동 매뉴얼](https://helpdesk.douzone.com/common/board/fileDownloadProc.do?attachSeq=383)은 특정 장비의 연동 절차다. 제품의 특정 연동 경로 존재를 보여주지만 결재·문서·일정 범용 API 계약은 아니다. 안내의 인증 정보를 수집하거나 근태 연동을 실행하지 않았다.

| 기능 | 내장 기능 확인 질문 | 커스텀 구현 판단 기준 |
|---|---|---|
| 요약·검색 | 어떤 문서·첨부·ACL을 지원하는가? | 근거 위치·최신 버전·권한 회수 확인 |
| 결재 도우미 | 상신 진행과 내 결재 대기를 구분하는가? | 원문 건수·상태·기한 대조 |
| 초안 작성 | 기관 서식·필수 항목·금액 대조를 지원하는가? | 승인된 규칙 표본만 결정적으로 검사 |
| 자동 실행 | 예약·실패 복구·중복 방지 범위는? | 실행 기록·중단 복구·결과 재조회 |

공식 API 검토는 공개 문서 탐색까지 진행했다. 결재·문서·일정 명세·인증 방식·라이선스 범위는 확보하지 못했다. 제한된 검색 결과를 API 부재의 증거로 삼지 않는다. 커스텀 개발은 수집 완전성·기관 규칙·수치 대조·출처 버전에 우선 집중한다.
