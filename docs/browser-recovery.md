# 브라우저 연결 문제 진단

설치, 브라우저 작업 공간 제어, 그룹웨어 로그인은 서로 다른 상태다. CLI가 실행된다고 로그인이나 조회까지 성공한 것은 아니다.

```bash
npm run doctor:browser
```

버전과 내장 Node 실행만 검사한다. 페이지를 열거나 로그인 정보를 읽거나 작업 공간을 생성하지 않는다. 브라우저 연동은 선택 사항이므로 이 진단은 기본 설치 및 CI에 포함하지 않는다.

## 오류별 처리

| 확인한 결과 | 의미와 다음 행동 |
|---|---|
| CLI 실행 파일 없음 | ego lite 설치와 PATH 등록 확인, 새 터미널에서 재검사 |
| CLI와 내장 Node 정상 | 설치 정상의 일부 근거. 페이지 제어 성공은 별도 확인 |
| `Task space does not exist` | 생성한 공간이 다음 호출에서 유효하지 않음. 그룹웨어 비밀번호나 쿠키 문제로 단정하지 않음 |
| `window is minimized` | Windows UI 관찰에서 실제 확인된 경우, 반환된 창을 복원하고 다시 관찰 |
| `no longer assigned` / `hard stop` | 작업 종료 또는 제어권 해제. 자동 재시도·다른 공간 생성·다른 도구로 우회 금지. 명시적 재개 후 도구가 안내한 절차 사용 |
| URL 판별 불가 | 기존 좌표·요소를 폐기하고 도구의 중단 지시 준수. URL 검사를 끄지 않음 |
| 업데이트 실패 | 설치 복구 완료로 표시하지 않음. 비밀번호 초기화나 프로필 삭제로 해결하려 하지 않음 |

단순 CLI 결함이고 제어 중단 지시가 없는 경우에만 허용된 Windows Computer Use 도구로 현재 창을 확인하는 대안을 검토한다. 반환된 창을 선택하고 현재 상태를 관찰한 뒤 한 동작씩 수행한다. 브라우저가 사용자 제어로 전환되거나 명시적 중단을 반환하면 다른 경로에서도 조작을 이어가지 않는다.

프로필·쿠키·인증 토큰을 복사하거나 원격 디버깅을 외부에 공개하는 방식은 이 프로젝트의 연결 방식이 아니다. 실제 로그인 세션은 각 PC의 브라우저에서 유지한다.

## 2026-10-22 확인 결과

- ego-browser 0.6.0.16, 내장 Node 24.21.0 실행 확인.
- 작업 공간 생성 결과는 반환되나 후속 호출에서 존재하지 않음 또는 제어 해제 오류 발생.
- 자체 업데이트 명령은 `Update failed (error 9)`를 반환. 업데이트 완료 아님.
- Windows 도구가 최소화된 창을 보고했고, 창 복원 후 실제 로그인된 그룹웨어 홈 화면 관찰에 성공.
- 정상 메뉴 클릭으로 전자결재 HOME과 미결 탭 확인. 이 결과는 **화면 조회 성공**이며 API 수집 커넥터 구현이나 전체 페이지 완전성 검증이 아님.
- 이후 CLI 재검사에서 명시적 제어 해제 신호가 발생하여 브라우저 조작 중단.

최소화가 CLI 오류의 원인이었다고 단정할 수 없다. 창 복원 이후에도 CLI 공간 오류가 재현됐으므로 별도 수명/제어 문제로 남아 있다. 실제 사용자명, 조직명, 문서 제목, 내부 화면 URL과 스크린샷은 공개 문서에 포함하지 않는다.

## 같은 날 후속 재개

사용자의 새 작업 공간 재개 확인 뒤 로컬 앱의 검색·초안·감사 화면을 같은 공간에서 연속 조작했다. 검색 화면의 DOM 반응형 측정과 일부 키보드 포커스까지 확인했다. 스크린샷 캡처와 다운로드 이벤트는 시간 초과됐고 이후 동일 공간이 다시 제어 해제를 반환했다. 그 시점부터 중단했으며 운영 그룹웨어를 새로 조사하지 못했다. 브라우저 연결 문제가 완전히 해결된 상태로 표시하지 않는다. [후속 검증 기록](followup-verification.md)에 범위를 남겼다.

## 2026-10-23 재현

사용자의 명시적 새 작업 공간 재개 승인 후 새 공간과 첫 탭 생성은 성공했다. 다음 호출에서 같은 공간을 재개하자 `Task space does not exist`가 반환되어 그룹웨어 탐색 전에 중단됐다. 새 공간 반복 생성이나 다른 브라우저 도구로 우회하지 않았다. 그룹웨어 로그인 만료 여부는 이 오류만으로 판단할 수 없다. 실제 연결을 완료하려면 브라우저 공간 수명 문제 해결 또는 별도로 제공된 공식 조회 계약이 필요하다.

이후 공식 업데이트는 다시 error 9였고, 사용자가 완전 종료·재시작한 뒤 새 공간 생성과 첫 이동을 한 호출에 묶어도 같은 오류가 재현됐다. 단순한 호출 사이 수명 문제만은 아니다. [전달 가능한 재현 기록](browser-bug-reproduction.md)을 남겼으며 외부에 자동 전송하지 않았다.
